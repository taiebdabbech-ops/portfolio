## 📋 Aperçu

Site portfolio personnel **responsive** (mobile-first) présentant mes projets, compétences et parcours académique.

### ✨ Fonctionnalités

- **Canvas Particle Network** — réseau de particules animé en arrière-plan (Canvas API + `requestAnimationFrame`)
- **Typed Effect** — animation texte sans librairie externe
- **Scroll Animations** — `IntersectionObserver` pour les apparitions au scroll
- **Skill Bars** — barres de compétences animées au scroll
- **Mobile Responsive** — menu hamburger, breakpoints 900px / 600px
- **Progress Bar** — barre de progression de lecture en haut de page
- **Formulaire de contact** — validation regex côté client
- **Smooth Scroll** — navigation fluide entre sections
- **Zéro dépendance** — aucun framework, aucune librairie JS externe
